How this reconstruction works

Proximity first. Workload check second.

1. Find nearby candidates

For the next assignment, the model considers the four nearest unassigned stops to the driver’s current location.

2. Build routes

It assigns a stop to the driver with the lowest estimated workload and favors a nearby stop with a dense cluster around it.

3. Balance the plan

A final pass moves stops between routes when doing so narrows the spread in estimated driver time.

This is a portfolio reconstruction to explain the type of routing logic and operational judgment used in the response. It is not a claim that the original work used this exact implementation or measured these simulated estimates.
